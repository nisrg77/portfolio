# Personal Portfolio

A modern, interactive personal portfolio website designed to showcase projects, experience, and skills. Built with React and TypeScript, it features a responsive design and smooth animations.

## 🚀 Tech Stack

- **Frontend Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/) (Framer Motion)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Backend/Server**: Express + Node.js (for form submissions / API handling)

## 📦 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nisrg77/portfolio.git
   cd portfolio
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173` (or another port depending on Vite's allocation).

## 🛠️ Available Scripts

- `npm run dev`: Starts the local development server (frontend + backend via TSX).
- `npm run build`: Builds the application for production using Vite and ESBuild.
- `npm run start`: Starts the production server from the built assets.
- `npm run preview`: Previews the Vite production build locally.
- `npm run lint`: Runs TypeScript compiler checks without emitting files.
